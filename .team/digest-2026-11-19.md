## Hygiene law going forward

1. **No per-event alert files.** Watchdog/tick alerts append one JSON line to `.team/alerts.jsonl` (ts, class key, payload). Classes are keyed by normalized signature (e.g. `build-stamp-change`), not timestamp.
2. **Rolling digest** `.team/digest-YYYY-MM-DD.md` is rebuilt per class at day rollover (or on lead trigger): first/last ts, count, class chain summary, actioned/disposition verdict. Individual events are reconstructible from `alerts.jsonl`, so the md is a summary, never the record of truth.
3. **Repeat suppression**: a class that has already fired N times (N=2 default) in a window escalates once as a class-level alert, then stops emitting until its disposition changes — turns 39 identical files into 1 row + 1 escalation.
